# 业务规则

## 1. 基本概念

| 概念 | 含义 |
| --- | --- |
| 班组（1/2/3班） | 人员组织，不是时间窗口 |
| 班次时段（早/中/晚） | 时间窗口，定义上下班起止 |
| 工作点 | 二维码打卡位置 |
| 业务日期 | 考勤归属日；跨午夜班次仍归入开始日 |
| 编制 | 某工作点某班次某岗位允许的在岗人数 |

## 2. 班次与业务日

- 每个地区配置 1/2/3 班的起止时间；`end <= start` 表示跨午夜。
- 示例：中班 18:00–次日 02:00，仍计入开始日。
- 业务时间固定按 `Asia/Shanghai` 解释。
- 加班使用 `shift_slot`（早/中/晚）标识时段，与基础出勤分开记录。

## 3. 工时口径

- 整班 = 8 小时；半班 = 4 小时。
- 同一员工同一业务日只允许一条有效出勤（部分唯一索引）；跨工作点重复扫码按「已上岗」处理。
- 加班单独建记录，不覆盖基础出勤。

## 4. 扫码与代签

- 员工只能为自己扫码；`hr`/`admin`/`chief` 可代他人扫码或代签。
- 代签是审批动作，值班长只能操作其绑定的工作点。
- 正式岗按编制硬拦：已满编则拒绝正式工越编上岗（前端置灰 + 后端兜底）。
- 实习/待岗不受正式编制硬拦，但仍记录出勤。

## 5. 负责人确认与封账

- 负责人按日确认当日名单；锁定后当日不可再代签/撤回/改工时。
- 月度导出锁：已封账月份的补录、代签、加班、改工时等操作被拦截。
- 解锁需人事专员/系统管理员操作，并留下审计。

## 6. 异常与对账

- 异常包括：当日无扫码、扫码与外部考勤不一致、跨班/跨点、半班、加班等。
- 外部考勤未配置时，对账结果按「缺失外部数据」提示，不会误判为正常出勤。
- 异常处理需记录处理人、动作与证据。

## 7. 权限

- 员工：本人扫码、本人记录。
- 值班长：绑定工作点的日确认、异常处理、代签。
- 人事专员/统计员：授权地区内的员工、编制、导出与异常。
- 系统管理员：字典、员工、权限、全局配置。

## 8. 首版边界

- 不计算工资、不做通用排班轮转。
- 仅支持 `Asia/Shanghai`。
- 外部集成（钉钉、劳勤 MySQL）为可选适配层，未配置时不启用。
